# Remember That Thing

Мобильное приложение для запоминания товаров: пользователь сканирует штрихкод, ставит оценку и комментарий, а в магазине по скану сразу видит, понравился ли ему товар. Плюс общие семейные списки покупок.

Полный продуктовый бриф и все принятые решения: @docs/PRODUCT.md — прочитай его перед началом любой задачи.

## Стек

- React Native + Expo, TypeScript (strict)
- Supabase: Postgres, auth, storage, edge functions
- Сканер штрихкода: expo-camera
- Вызовы ИИ-модели — только из Supabase edge functions, ключи никогда не в клиенте

## Как мы работаем

- Владелец проекта — продюсер, не программист. Объясняй решения коротко и простым языком, особенно когда предлагаешь выбор.
- Общаемся по-русски. Код, имена переменных, комментарии в коде и коммиты — на английском.
- Делаем маленькими шагами: после каждого шага приложение должно запускаться и проверяться на телефоне через Expo Go.
- Прежде чем ставить новую библиотеку — коротко скажи зачем.
- Строки интерфейса сразу выносить в файлы локализации (en, ru, uk, ro), без хардкода текста в компонентах.

## Ключевые архитектурные правила

- Общая карточка товара и личный слой пользователя (оценка, комментарий, личные теги) — разные таблицы.
- У товара может быть несколько штрихкодов.
- Категории — ID с переводами, а не строки.
- Атрибуты («солёные», «без сахара») — не категории.
